# Manage available positions

Start with the branded Word template in [`templates/SOPliance Position Template.docx`](../templates/SOPliance%20Position%20Template.docx). Save a completed copy for each position; keep the blank master outside this folder.

Upload a job description into this folder and commit it to `main`. GitHub automatically rebuilds and publishes the careers list. Delete a file and commit to remove that position. Allow a few minutes for deployment.

Supported files: `.pdf`, `.docx`, `.doc`, `.txt`, and `.md`. This README and files beginning with a dot or underscore are excluded.

The filename becomes the displayed job title. Examples (not actual openings):

- `Desktop Support Technician.pdf`
- `Fiber Optic Technician - Orlando.docx`
- `Project Coordinator.md`

Underscores become spaces. Include location or a reference number in the filename to distinguish similar roles.

Put the full description, location, employment type, qualifications, and application requirements inside the document. Each listing offers a document link and an application email to info@sopliance.com with the position title prefilled.

The list supports 50+ files and searches by title. No manual HTML edits are needed. Only upload information intended for public website visitors; do not include private candidate data.
