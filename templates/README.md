# SOPliance position template

1. Open `SOPliance Position Template.docx` in Word and save a separate copy for each role.
2. Replace the title and every bracketed placeholder. Remove optional sections that do not apply. Confirm the role details and approved compensation before publishing.
3. Keep the unique position reference in the document and the application subject line. All applications must identify a specific position.
4. Save the completed file as `Position Title - Location - Reference.docx` or export it as a PDF with the same filename. The filename becomes the website listing title and email subject.
5. Upload only the completed job description to the repository's `positions` folder and commit to `main`. The site automatically publishes the listing. Delete that file and commit to remove it.

The blank template stays in `templates`, outside the public job listings. Never upload the blank template or these instructions to `positions`.
